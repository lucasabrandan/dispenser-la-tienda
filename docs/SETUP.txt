# 🔧 SETUP - Guía de Instalación y Configuración

Instrucciones paso a paso para configurar el proyecto localmente.

---

## 📋 Requisitos Previos

### Hardware Mínimo
- CPU: Dual core 2GHz+
- RAM: 4GB (8GB recomendado)
- Disco: 5GB disponibles

### Software Requerido

| Software | Versión Mínima | Descargar |
|----------|---|---|
| Java JDK | 21 | https://jdk.java.net/21/ |
| Maven | 3.8+ | https://maven.apache.org/ |
| Node.js | 18 LTS | https://nodejs.org/ |
| npm | 9+ | Incluido con Node.js |
| PostgreSQL | 15 | https://www.postgresql.org/ |
| Git | 2.30+ | https://git-scm.com/ |

### Verificar Instalación

```bash
# Java
java -version

# Maven
mvn -version

# Node.js y npm
node -v
npm -v

# Git
git --version

# PostgreSQL
psql --version
```

## 🗄️ Configuración de Base de Datos

### 1. Crear Base de Datos

```bash
# Abrir terminal PostgreSQL
psql -U postgres

# Crear BD
CREATE DATABASE dispenser_la_tienda;

# Crear usuario (opcional)
CREATE USER dispenser_admin WITH PASSWORD 'tu_password_seguro';
GRANT ALL PRIVILEGES ON DATABASE dispenser_la_tienda TO dispenser_admin;

# Conectar a BD
\c dispenser_la_tienda
```

### 2. Verificar Conexión

```bash
# Desde terminal
psql -U postgres -d dispenser_la_tienda -c "SELECT version();"

# Debería mostrar información de PostgreSQL
```

## ⚙️ Configurar Backend

### 1. Navegar a carpeta backend

```bash
cd backend
```

### 2. Configurar application-dev.properties

```bash
# Abrir archivo de configuración
nano src/main/resources/application-dev.properties
```

**Contenido típico:**

```properties
# Server
server.port=8080

# Database
spring.datasource.url=jdbc:postgresql://localhost:5432/dispenser_la_tienda
spring.datasource.username=postgres
spring.datasource.password=tu_password

# JPA/Hibernate
spring.jpa.hibernate.ddl-auto=validate
spring.jpa.show-sql=false
spring.jpa.properties.hibernate.dialect=org.hibernate.dialect.PostgreSQLDialect

# Flyway (migraciones SQL)
spring.flyway.enabled=true
spring.flyway.locations=classpath:db/migration

# Logging
logging.level.root=INFO
logging.level.com.dispenserlatienda=DEBUG

# CORS
app.cors.allowed-origins=http://localhost:3000
```

### 3. Compilar Backend

```bash
# Desde carpeta /backend
mvn clean package

# Debería terminar con: BUILD SUCCESS
```

### 4. Ejecutar Backend

```bash
# Opción 1: Con Maven
mvn spring-boot:run

# Opción 2: JAR generado
java -jar target/dispenser-la-tienda-1.0.0.jar

# Debería mostrar:
# Started DispenserLaTiendaApplication in X seconds
```

### 5. Verificar Backend

```bash
# En otra terminal
curl http://localhost:8080/health

# Debería retornar: {"status":"UP"}
```

## 💻 Configurar Frontend

### 1. Navegar a carpeta frontend

```bash
cd frontend
```

### 2. Instalar Dependencias

```bash
npm install

# Esto crea carpeta node_modules/ (puede tardar)
```

### 3. Crear .env (opcional)

```bash
# Crear archivo
echo "VITE_API_BASE_URL=http://localhost:8080" > .env.local
```

### 4. Ejecutar Frontend

```bash
# Desarrollo con hot-reload
npm run dev

# Debería mostrar:
# VITE v4.0.0  ready in XXX ms
# ➜  Local:   http://localhost:3000/
```

### 5. Acceder a Frontend

Abrir navegador:
```
http://localhost:3000
```

## 🐛 Solucionar Problemas

### Error: "Port 8080 already in use"

```bash
# Linux/Mac
lsof -i :8080
kill -9 <PID>

# Windows
netstat -ano | findstr :8080
taskkill /PID <PID> /F
```

### Error: "Cannot connect to database"

```bash
# Verificar BD está corriendo
# En otra terminal:
psql -U postgres -d dispenser_la_tienda

# Si error de credenciales, cambiar en application-dev.properties
```

### Error: "Module not found" (Frontend)

```bash
# Limpiar e reinstalar
rm -rf node_modules package-lock.json
npm install
npm run dev
```

### Error: "Compilation failed" (Backend)

```bash
# Limpiar caché Maven
mvn clean

# Reintentar compilación
mvn package
```

## 📁 Estructura de Archivos Generados

Después de compilar/ejecutar, se crean:

```
backend/
├── target/                    # Archivos compilados
│   └── dispenser-la-tienda-1.0.0.jar
└── .m2/                       # Caché Maven (local)

frontend/
├── node_modules/              # Dependencias npm (~500MB)
├── dist/                       # Build para producción
└── .env.local                  # Configuración local (ignorado en git)
```

**Nota:** Estos archivos NO se commitean a GitHub (están en .gitignore)
